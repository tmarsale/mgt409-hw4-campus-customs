# Local data pack goes here

The database and product photos are **not** in this repository, because they contain customer accounts and licensed images. Unzip the course data pack (`data.zip`) so this folder contains:

```
hw4/data/
├── campus_customs.db      # SQLite: catalogue, inventory, users, chat_messages
└── products/              # 102 product photos (.jpg)
```

Unzip so there is no extra nested `data/data/` folder. Everything in this folder except this README is ignored by Git.
